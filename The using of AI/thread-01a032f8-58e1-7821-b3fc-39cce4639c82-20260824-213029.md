**学习逻辑**
我建议先做一个 `诊断 -> 学习 -> 练习 -> 复习 -> 巩固` 的闭环。

1. `语法地图`
用户先看到语法模块入口，比如：
- 时态
- 句子成分
- 从句
- 主谓一致
- 非谓语
- 冠词/代词/介词

2. `诊断测试`
每个模块先做 5-10 题小测，目的是判断：
- 会不会
- 错在哪类规则
- 是否需要从基础解释开始

3. `知识讲解`
每个知识点页面只讲一件事：
- 规则
- 对比例句
- 常见错误
- 一条记忆口诀

4. `分层练习`
练习不要只有选择题，建议 4 种：
- 判断正误
- 选择填空
- 句子改错
- 句子重组/造句

5. `错题回收`
错题自动进入“薄弱点清单”，并按知识点聚合，而不是只存题目。

6. `间隔复习`
系统按掌握度安排复习：
- 新错题当天复习
- 复习正确后延后
- 多次错误就降级回讲解页

  错题和薄弱点进入复习队列，下一次优先处理。

这套逻辑其实就是把 InRead 的“只清掉当前阅读障碍”换成“只清掉当前语法障碍”。

**首页文案逻辑**
首页也照这个节奏走：
- Hero 标题：产品名
- 一句副标：比如“不是背完整语法书，只解决你眼前这道题”
- 两个按钮：`Start` / `Create account`
- 三张原则卡片：
  - Choose one grammar point
  - Clear the smallest rule gap
  - Return to real practice
